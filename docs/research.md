# MX Deposit selection, 15 October 2026

**The price list.** Seequent's own MX Deposit pricing page lists three 12-month named licences, in US dollars excluding tax: Standard User US$3,705 ("All standard logging features", "Data import, export and modification", "System configuration"), Shift User US$5,055 (two user profiles sharing one licence, not at the same time) and Reviewer US$1,265 (read only). "Only 12 month named licences are available to purchase online. For shared and enterprise licences, please contact us." Source: [seequent.com/company/partners/mx-deposit/pricing](https://www.seequent.com/company/partners/mx-deposit/pricing/), checked today.

**What a small explorer pays.** Ten geologists and field technicians on Standard licences is US$37,050 a year. Most junior explorers also retain a database consultant to manage imports, validation and QAQC reporting, which the licence does not cover. The bigger rival, acQuire's GIM Suite, publishes no price.

**The way out.** "The default behaviour of the export is that every table is exported as a CSV file and the headers in the CSV file match exactly as they appear in MX Deposit." The files download as one ZIP. Source: [Seequent Community, "Exporting Data from MX Deposit"](https://community.seequent.com/discussion/2103/exporting-data-from-mx-deposit).

**The rules.** JORC Code 2012 Table 1 Section 1 and the WA Guidelines for Mineral Exploration Reports on Mining Tenements (October 2025), quoted in `docs/compliance.md`.

Scores, in order: annual bill 3, data-shaped 5, our buyers 3, search demand 2, one-session buildable 4, import path 5. Total 22/30. The data is a textbook fit: collars, surveys, intervals, samples and results, five tables and a handful of views. The weekly work is rule-shaped (QAQC limits, chain of custody, report dates), which is what a database and an agent do well. Buyers are the many ASX-listed and private junior explorers in Australia and New Zealand with 10 to 50 staff. Search demand for "MX Deposit alternative" is thin; the page also targets "drillhole database software" and "geological database software".
