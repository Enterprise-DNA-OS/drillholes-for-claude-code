---
description: Significant intercepts: length-weighted runs at or above a cut-off, with internal dilution and a minimum length, for one hole or every hole.
---

Run `npm run dh -- intercepts [--hole=<hole>] [--element=Au] [--cutoff=0.5] [--dilution=2] [--min-length=1] --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Write each as "5 m @ 3.22 g/t Au from 31 m". Ask for the cut-off and dilution the company reports at if the operator has not given them, and say which were used.
