---
description: Annual tenement reports: the year each covers, the due date (60 days after the anniversary in WA), whether it is lodged, and the holes and metres drilled in the year.
---

Run `npm run dh -- reports --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Lead with anything overdue, then due within the notice window. For a report due, offer `report-files` to lay out the drilling data for it.
