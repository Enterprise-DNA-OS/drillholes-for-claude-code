description: The Monday review for the exploration manager: metres drilled, results in, batches waiting, QC failures, reports due, holes to rehabilitate and rule checks by rule.
---

Run `npm run dh -- weekly-review --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Write it as a one-page brief in this order: the numbers (metres drilled, batches waiting, QC failures open), the three things to decide this week, then each section in two or three lines. Save it to `drafts/weekly-review-<date>.md`.
