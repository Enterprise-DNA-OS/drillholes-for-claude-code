---
description: Lay out the collar, survey, geology, assay and QAQC tables for a tenement's annual report, with the datum, projection and zone stated, into a new folder.
---

Run `npm run dh -- report-files --tenement=<tenement> --out=<new folder> --json`.

Present the result as a short table in plain words. If a name matches more than one record the command lists them: ask which one.

Tell the operator these are the tables to copy into the department's templates, list any hole with results still pending (those go in next year's report with the collar file), and remind them of the due date.
